# VoiceScribe 🎙️ — 音声文字起こしWebアプリケーション

ブラウザ標準の **Web Speech API** と、超高速なAI音声認識エンジン **Groq Whisper API** を組み合わせた、モダンで洗練されたデザインの音声文字起こしWebアプリケーションです。

ユーザー登録不要で、マイクからのリアルタイム文字起こしと、音声・動画ファイルのアップロードによる高精度な文字起こしの2つのモードを即座に利用できます。

---

## 🚀 主な機能

### 1. 🎙️ リアルタイムマイク入力モード
- **ブラウザ完結の音声認識**: Web Speech API（SpeechRecognition）を利用し、サーバーを介さずにデバイス上で高速にリアルタイム文字起こしを行います。
- **マルチリンガル対応**: 日本語、英語、中国語、韓国語の4つの言語に対応。
- **直感的なフィードバック**: 
  - 録音中の経過時間を示すリアルタイムタイマー。
  - 音声入力の強弱を視覚的に表現するスムーズな **CSS波形アニメーション**。
- **キーボードショートカット**: マイクモード時、スペースキーの押下で簡単に録音の開始・停止を切り替え可能。

### 2. 📁 ファイル読み込みモード (Groq Whisper & 自動音声圧縮)
- **超高速・高精度AI認識**: Groqの提供する `whisper-large-v3-turbo` モデルを採用し、長時間の音声ファイルも数秒で正確にテキスト化します。
- **🎬 動画ファイル対応＆ブラウザ内自動音声圧縮**:
  - **動画からの自動音声抽出**: MP4, MOV, WebM, MKV などの動画ファイルから、ブラウザの **Web Audio API** で音声トラックのみを高速抽出。
  - **自動MP3軽量化（lamejs）**: 音声認識に最適な設定（16kHz モノラル / 64kbps）で自動圧縮。**100MB〜200MB超のZoom録画動画（40〜50分程度）でも、数MB〜十数MBに圧縮** して Whisper API の25MB制限を自動クリアします。
  - **抽出したMP3の保存**: 抽出・圧縮した音声データをワンクリックでローカルに保存（ダウンロード）することも可能。
- **ドラッグ＆ドロップ対応**: 直感的なファイルアップロードエリアを搭載し、ドラッグ＆ドロップまたはクリック選択で簡単にファイルを指定できます。
- **多様なフォーマット対応**: `mp3`, `mp4`, `mov`, `m4a`, `wav`, `webm`, `mpeg`, `mpga`, `mkv`, `flac`, `ogg` など主要なオーディオ・ビデオ形式に対応。
- **スマートな処理フロー**:
  - 音声抽出 → MP3圧縮 → Groq API送信の各ステップをプログレスバーと進捗テキストで可視化。

### 3. ✍️ テキスト操作・エクスポート
- **リアルタイム文字数カウント**: 文字起こし結果の文字数を常にカウントし表示。
- **ワンクリックコピー**: クリップボードへのコピー（モダンブラウザ対応の `navigator.clipboard` と、レガシーブラウザ用のフォールバック処理を両方実装）。
- **ファイルダウンロード**: 文字起こしテキストをタイムスタンプ付きの `.txt` ファイルとして即座に保存可能。
- **安全なクリア**: 誤操作を防ぐための確認ダイアログ付きのテキストクリア機能。

## 🎨 UI/UXデザインのこだわり

ポートフォリオとして視覚的なアピール度を最大化するため、モダンなWebデザインのトレンドを取り入れています。
- **Glassmorphism（グラスモルフィズム）**: 半透明のカード背景（`backdrop-filter`）と微細な境界線のライトエフェクトにより、奥行きのある高級感を演出。
- **アンビエント・グロー背景**: 背景に配置された巨大な2つのグラデーション円が、CSSの `radial-gradient` と `blur` によって柔らかく発光し、近未来的なダークモードを構成。
- **滑らかなマイクロアニメーション**: 
  - マイクボタンホバー時のスケール変化とネオン風のパルスアニメーション。
  - タブ切り替えやホバー時のイージング（`cubic-bezier`）による、ネイティブアプリのような操作感。
- **トースト通知**: 操作完了時（コピー完了、ダウンロード完了など）に画面下部からスムーズにフェードインする通知機能。
- **レスポンシブデザイン**: スマートフォン、タブレット、PCのすべての画面サイズに最適化されたグリッド＆フレックスボックスレイアウト。

## 🛠️ 技術スタック

| 役割 | 使用技術 | 選定理由 |
| :--- | :--- | :--- |
| **マークアップ** | HTML5 | セマンティックなマークアップによるアクセシビリティの確保 |
| **スタイリング** | Vanilla CSS (CSS3) | フレームワークに依存しない自由なスタイリングと軽量化、CSS変数による一貫したデザインシステム |
| **ロジック** | Vanilla JavaScript (ES6+) | ページの読み込み速度とパフォーマンスを追求 |
| **音声抽出・リサンプリング** | Web Audio API / OfflineAudioContext | サーバー不要でブラウザ上で高速に動画から音声を分離し16kHzモノラルへ最適化 |
| **音声圧縮** | lamejs | ブラウザ完結で軽量MP3（64kbps）へ高圧縮し、Whisperの25MB制限を突破 |
| **音声認識 (ローカル)** | Web Speech API | サーバーレスでのリアルタイム音声認識を実現するため |
| **音声認識 (クラウド)** | Groq Whisper API | `whisper-large-v3-turbo` モデルによる圧倒的な認識速度と日本語精度の両立 |

## 🔒 セキュリティとプライバシー

- **Groq APIキーの保護**: 入力されたAPIキーはサーバーを経由せず、ユーザーのブラウザの **ローカルストレージ（localStorage）** に直接保存されます。
- キーの表示・非表示を切り替えるトグルボタンを搭載し、画面共有時の映り込みを防止します。

## 🚦 動作環境・セットアップ

### 推奨ブラウザ
- **Google Chrome**（マイク入力・ファイル読込両対応）
- **Microsoft Edge**（マイク入力・ファイル読込両対応）
- **Safari / Firefox**（ファイル読込対応、マイク入力はブラウザの実装状況に依存します）

### ローカルでの起動方法
特別なバックエンドサーバーの構築は不要です。ファイルをブラウザで直接開くか、ローカルサーバーを起動してください。

1. このリポジトリをクローンまたはダウンロードします。
2. ディレクトリ内の `index.html` をブラウザで開きます。
3. （推奨）VScodeの `Live Server` などのローカル開発サーバーを使用して開くと、スムーズに動作します。
