============================================================
VoiceScribe — 音声文字起こしアプリケーションの概要
============================================================

【アプリ概要】
VoiceScribe（ボイススクライブ）は、ブラウザだけで動作する、インストール不要のリアルタイム音声文字起こし・ファイル文字起こしアプリケーションです。

【主な機能】
1. マイク入力（リアルタイム文字起こし）
   - ブラウザ標準の Web Speech API を使用し、話した音声をリアルタイムで文字に変換します。
   - 日本語、英語、中国語、韓国語などの複数言語に対応しています。
   
2. ファイル読込（動画音声抽出・自動圧縮・高精度文字起こし）
   - 超高速AI推論プラットフォームである「Groq API」（モデル: Whisper-large-v3-turbo）を利用します。
   - 録音された音声だけでなく、Zoomなどの録画動画（mp4, mov, webm, mkv など）もそのままドラッグ＆ドロップ可能。
   - ブラウザ標準の Web Audio API で動画から音声のみを自動抽出し、lamejs で 64kbps MP3 に高圧縮することで、100MB〜200MB超の動画でも自動的に25MB以内に軽量化して文字起こしできます。
   - 抽出したMP3ファイルをワンクリックでダウンロード保存することも可能です。

3. テキスト操作ユーティリティ
   - 文字起こし結果のリアルタイム文字数カウント。
   - ワンクリックでの「クリップボードへのコピー」。
   - テキストファイル（.txt）としての「ローカルダウンロード」。
   - 入力内容の一括クリア機能。

【技術スタック】
- HTML5 (セマンティックマークアップ)
- CSS3 (バニラCSS、グラスモフィズム風のモダンなデザイン、レスポンシブ対応)
- JavaScript (ブラウザ標準の vanilla JS)
- lame.min.js (クライアント側MP3エンコードライブラリ)
- 利用API / 技術:
  - Web Audio API / OfflineAudioContext (音声抽出・16kHzリサンプリング)
  - Web Speech API (ブラウザ標準マイク認識)
  - Groq Whisper API (音声ファイル文字起こし用)

【セキュリティとプライバシー】
- サーバーを仲介しないため、個人情報や音声データが第三者のサーバーに蓄積されることはありません。
- 入力した Groq API キーは、ブラウザのローカルストレージ（LocalStorage）にのみ安全に保存されます。

【使用手順】
■ マイク入力の場合：
1. 「マイク入力」タブを選択します。
2. 認識させたい言語（例: 日本語）を選択します。
3. マイクアイコンの丸いボタンを押して、話し始めます。
4. 話し終わったら、再度ボタンを押して停止します。

■ ファイル読込の場合：
1. 「ファイル読込」タブを選択します。
2. 事前に取得した Groq API Key（gsk_...）を入力します。
3. 音声または動画ファイルをドラッグ＆ドロップするか、クリックして選択します。
4. 音声の言語を指定します。
5. 「文字起こし開始」ボタンを押します。数秒〜数十秒で結果が表示されます。

【GitHubでの管理とWeb公開手順】
■ ローカルからGitHubへの初回アップロード（プッシュ）手順：
1. ターミナルでプロジェクトフォルダに移動します。
   cd c:\Users\Iri71\transcription-app
2. Gitリポジトリを初期化します。
   git init
3. すべてのファイルをステージングします。
   git add .
4. 最初のコミットを行います。
   git commit -m "Initial commit"
5. GitHub上で新規リポジトリ（空の状態）を作成します。
6. ローカルとGitHubを紐付けてプッシュします。
   git branch -M main
   git remote add origin https://github.com/あなたのユーザー名/transcription-app.git
   git push -u origin main

■ コードの更新方法（変更をGitHubに反映するとき）：
1. 変更したファイルをステージングに追加します。
   git add .
2. コミットを作成します。
   git commit -m "変更内容の説明"
3. GitHubにプッシュします。
   git push

■ GitHub PagesによるWeb無料公開手順：
1. GitHubのリポジトリページから「Settings」タブを開きます。
2. 左メニューから「Pages」を選択します。
3. Build and deploymentセクションの「Branch」を「None」から「main」に変更し、「Save」をクリックします。
4. 数分後、ページ上部に表示されるURL（ https://あなたのユーザー名.github.io/transcription-app/ ）にアクセスすると、全世界からWebアプリとして使用可能になります。
